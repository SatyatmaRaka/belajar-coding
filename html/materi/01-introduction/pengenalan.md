# Pengenalan HTML

-> HTML atau HyperText Markup Language adalah Sebuah bahasa markah untuk membuat halaman web.

-> Penamaan Utama Untuk Website yang pertama kali dijalankan atau dibuat ialah index.html.

-> Menjalankan HTML pertama kali bisa dengan shift+! nanti akan muncul emmet abbreviation,lalu klik tab

# Analogi HTML

-> Menurut saya HTML ini bisa dianalogikan sebagai Kerangka Manusia.

# Struktur Dasar HTML

-> <!doctype html>, Memberi tahu browser bahwa ini dokumen HTML5. Selalu ditulis paling atas.
-> <html lang="en"> </html>, Pembungkus seluruh halaman. lang menyatakan bahasa isinya. Untuk halaman berbahasa Indonesia, pakai lang="id".
-> <head> </head>, Informasi tentang halaman yang tidak tampil di layar.
-> <meta charset="UTF-8" />, Mengatur pengkodean karakter agar huruf seperti é atau emoji tampil benar.
-> <meta name="viewport" content="width=device-width, initial-scale=1.0" />, Agar halaman menyesuaikan lebar layar HP. Penting untuk tampilan responsif.
-> <title>Pengenalan HTML</title>, Judul yang muncul di tab browser.
-> <body></body>, Seluruh isi yang tampil di layar: teks, gambar, tombol, dll.

# Penamaan File HTML

-> Huruf kecil semua
-> Tanpa spasi, pakai strip (-) untuk pemisah kata
-> Tanpa karakter khusus
-> Diakhiri .html
-> Nama menjelaskan isi (form-daftar.html, bukan baru.html)
-> Halaman utama bernama index.html

# Pengenalan Tag HTML

-> Tag adalah sebuah penanda awalan dan akhiran dari sebuah elemen di HTML dimana dibuat dari kurung siku (<.....>).
Contoh : <p>, <a>, <body>, dan lainya.

Setiap tag mempunya fungsi masing-masing.

Contoh :

-> <h1>Karaka</h1>, tag ini untuk membuat Heading 1,ada lagi sampai Heading 6.

-> <p>Karaka ialah seorang programmer </p>, tag ini untuk membuat Paragraf,dsb.
